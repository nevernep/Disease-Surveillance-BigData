# คู่มือทำรายงาน Power BI บนเว็บ (ไม่ต้องใช้ Power BI Desktop)

คู่มือนี้พาทำรายงานเฝ้าระวังโรคบน **Power BI Service (app.powerbi.com)** ทีละขั้น
ตั้งแต่อัปโหลดข้อมูลจนแชร์รายงาน ใช้เวลาประมาณ 1–2 ชั่วโมง

ทำครบแล้วจะได้รายงาน 5 หน้า: ภาพรวม, แนวโน้มรายเดือน, รายเขต, อายุ/เพศ, คุณภาพข้อมูล

## 1. นำข้อมูลเข้า Power BI

1. เข้า https://app.powerbi.com แล้วเลือก **My workspace** (หรือ workspace ของกลุ่ม)
2. กด **+ New item / New / Upload** แล้วเลือกนำเข้าไฟล์ Excel (จากเครื่องหรือจาก OneDrive)
3. หน้า **Power Query → เลือกข้อมูล** จะแสดงรายการ 16 รายการ
   - ✅ **ติ๊กเฉพาะ 8 ตัวที่ชื่อไม่มีคำว่า `sheet_` นำหน้า** เช่น `fact_disease_cases`, `dim_sex`
   - ❌ **อย่าติ๊กตัวที่ขึ้นต้นด้วย `sheet_`** ตัวพวกนี้คือชีตดิบ ถ้าเลือก ตาราง `dim_sex` และ `data_quality` จะได้ชื่อคอลัมน์เป็น Column1, Column2
4. ดูตัวอย่างข้อมูลทางขวา แถวแรกต้องเป็นชื่อคอลัมน์ เช่น `date_key` แล้วกด **ถัดไป / แปลงข้อมูล**

## 2. ตรวจชนิดข้อมูล (หน้า Power Query)

ก่อนโหลด ให้เลือกตารางทางซ้ายแล้วดูไอคอนชนิดข้อมูลที่หัวคอลัมน์ ถ้าไม่ตรงตามตารางนี้ ให้กดที่ไอคอนแล้วเปลี่ยน

| ตาราง | คอลัมน์ | ชนิดที่ถูก |
|---|---|---|
| `dim_date` | `month_start` | **วันที่ (Date)** |
| `dim_date` | `month_label` | **ข้อความ (Text)** ระวัง Power BI ชอบเดาเป็นวันที่ |
| ทุกตาราง | คอลัมน์ที่ลงท้าย `_key`, `year_be`, `total_cases`, `population` | จำนวนเต็ม (Whole number) |
| `fact_disease_cases`, `dim_sex` | `sex` | ข้อความ |
| `dim_district` | `is_bangkok_district` | True/False |

กด **บันทึก / สร้างรายงาน**

## 3. บันทึกรายงาน

**ไฟล์ → บันทึก** ตั้งชื่อ `Disease Surveillance Bangkok` ควรกดบันทึกบ่อยๆ ระหว่างทำ

## 4. สร้างความสัมพันธ์ระหว่างตาราง

1. กด **เปิดแบบจำลองความหมาย (Open semantic model)** ที่แถบด้านบน
2. มุมขวาบน สลับจาก **กำลังดู** เป็น **กำลังแก้ไข**
3. ลากคอลัมน์จากตาราง fact ไปปล่อยบนคอลัมน์ชื่อเดียวกันในตาราง dim ให้ครบ 6 เส้น

| # | จาก | ไป |
|---|---|---|
| 1 | `fact_disease_cases[date_key]` | `dim_date[date_key]` |
| 2 | `fact_disease_cases[district_key]` | `dim_district[district_key]` |
| 3 | `fact_disease_cases[disease_key]` | `dim_disease[disease_key]` |
| 4 | `fact_disease_cases[age_group_key]` | `dim_age_group[age_group_key]` |
| 5 | `fact_disease_cases[sex]` | `dim_sex[sex]` |
| 6 | `fact_population[district_key]` | `dim_district[district_key]` |

4. **ดับเบิลคลิกทุกเส้น** แล้วตรวจว่าตั้งค่าเป็น:
   - Cardinality: **หลายต่อหนึ่ง (\*:1)**
   - ทิศทางตัวกรองข้าม: **เดียว (Single)**

   ⚠️ ถ้าเส้นไหนเป็น "ทั้งสอง (Both)" ให้แก้เป็น Single **โดยเฉพาะเส้น dim_district ↔ fact_disease_cases**
   ถ้าเส้นนี้กรองได้ 2 ทาง incidence จะสูงเกินจริง เพราะตัวหารจะเหลือแค่เขตที่มีผู้ป่วยโรคนั้น
5. ⚠️ **ห้ามเชื่อม `fact_population` กับ `dim_date`, `dim_disease`, `dim_age_group`, `dim_sex`**
   ถ้า Power BI สร้างเส้นพวกนี้ให้เอง ให้คลิกขวาที่เส้นแล้วลบ ตัวหารจะดึงปีผ่านสูตร DAX แทน
6. `data_quality` ไม่ต้องเชื่อมกับตารางไหน

## 5. ตั้งค่าการเรียงลำดับ

ยังอยู่ในหน้าโมเดล:

1. คลิกคอลัมน์ `dim_date[month_label]` → **เรียงลำดับตามคอลัมน์ (Sort by column)** → `month_start`
   ถ้าไม่ทำ เดือนในกราฟจะเรียงตามตัวอักษร (ก.ค. มาก่อน ม.ค.)
2. คลิกคอลัมน์ `dim_age_group[age_group]` → **เรียงลำดับตามคอลัมน์** → `age_group_key`
3. ซ่อนคอลัมน์ key ที่ผู้ชมไม่ต้องเห็น (คลิกขวา → ซ่อน) เช่น `*_key` ในตาราง fact

## 6. เพิ่มสูตร DAX (Measures)

1. คลิกตาราง `fact_disease_cases` → **หน่วยวัดใหม่ (New measure)**
2. คัดลอกสูตรจาก [`powerbi/measures.dax`](../powerbi/measures.dax) **ทีละสูตร** (บรรทัดที่ขึ้นต้นด้วย `//` เป็นคำอธิบาย ไม่ต้องคัดลอก) แล้วกด Enter
3. ทำซ้ำจนครบ:

| Measure | ใช้ทำอะไร | ตั้งรูปแบบ |
|---|---|---|
| `Total Cases` | จำนวนผู้ป่วยรวม | จำนวนเต็ม, มีคอมมา |
| `Source Records` | จำนวนแถวต้นทาง | จำนวนเต็ม |
| `Population` | ประชากรในขอบเขตที่เลือก | จำนวนเต็ม |
| `Incidence Rate per 100k` | อัตราป่วยต่อแสนประชากร | ทศนิยม 2 ตำแหน่ง |
| `Population Coverage %` | สัดส่วนเขตที่มีข้อมูลประชากร | เปอร์เซ็นต์ |
| `Population Coverage Status` | ข้อความสถานะข้อมูลประชากร | — |
| `Case Share %` | สัดส่วนผู้ป่วยในกลุ่มอายุหรือเพศ | เปอร์เซ็นต์ |
| `District Rank` | อันดับเขต | จำนวนเต็ม |
| `Cases Previous Month`, `Month over Month Cases %` | เทียบกับเดือนก่อน | %, สำหรับตัว % |
| `Cases Same Month Last Year`, `Year over Year Cases %` | เทียบกับเดือนเดียวกันปีก่อน | %, สำหรับตัว % |

> `Incidence Rate per 100k` จะ**ว่างโดยตั้งใจ**เมื่อกรองตามอายุหรือเพศ เพราะไม่มีข้อมูลประชากรแยกอายุ/เพศ
> ถ้าดูตามอายุหรือเพศ ให้ใช้ `Case Share %` แทน

กลับไปหน้ารายงาน (ปิดหน้าโมเดลหรือกด **เปิดรายงาน**)

## 7. สร้างรายงาน 5 หน้า

วิธีสร้างกราฟ: เลือกชนิดกราฟจากแผง **การจัดรูปแบบการสร้างภาพ** แล้วลากฟิลด์จากแผง **ข้อมูล** ไปใส่ช่องที่กำหนด
ใช้ฟิลด์ข้อความ เช่น `month_label`, `district_name` แทนคอลัมน์ `_key` เสมอ

### หน้า 1: ภาพรวม
- **บัตร (Card)** 3 ใบ: `Total Cases`, `Incidence Rate per 100k`, `Population Coverage Status`
- **แผนภูมิเส้น**: แกน X = `dim_date[month_label]`, ค่า = `Total Cases`, คำอธิบาย (Legend) = `dim_disease[disease_name]`
- **แผนภูมิแท่งแนวนอน**: แกน Y = `dim_disease[disease_name]`, ค่า = `Total Cases`
- **ตัวแบ่งส่วนข้อมูล (Slicer)**: `dim_date[year_be]`, `dim_disease[disease_name]`

### หน้า 2: แนวโน้ม
- **แผนภูมิเส้น**: X = `month_label`, ค่า = `Total Cases`
- **บัตร**: `Month over Month Cases %`
- **Slicer**: โรค, เขต

### หน้า 3: รายเขต
- **แผนภูมิแท่ง**: แกน = `dim_district[district_name]`, ค่า = `Total Cases` เรียงจากมากไปน้อย
- **ตาราง (Table)**: `district_name`, `Total Cases`, `Population`, `Incidence Rate per 100k`, `District Rank`
- **Slicer**: ปี, โรค

### หน้า 4: อายุและเพศ
- **แผนภูมิแท่งแบบเรียงซ้อน**: แกน = `dim_age_group[age_group]`, ค่า = `Total Cases`, Legend = `dim_sex[sex_label]`
- **เมทริกซ์**: แถว = `age_group`, คอลัมน์ = `sex_label`, ค่า = `Case Share %`
- **Slicer**: ปี, โรค

### หน้า 5: คุณภาพข้อมูล
- **ตาราง**: `data_quality[layer]`, `rule`, `observed`, `threshold`, `status`
- **บัตร**: นับจำนวน rule ที่ `status` = FAIL (ลาก `rule` ใส่บัตร เลือก "จำนวน" แล้วใส่ตัวกรอง `status` = FAIL)
- คำอธิบาย status: `PASS` = ผ่าน, `FAIL` = ไม่ผ่าน, `SKIP` = rule นี้ไม่ใช้ในโหมดที่รัน

### ข้อความกำกับที่ควรใส่ (กล่องข้อความ)
ใส่ในหน้า 1 และหน้า 3:

> อัตราป่วยต่อแสนประชากรเป็น **อัตราสะสม** ตามช่วงที่มีข้อมูล (2568: มิ.ย.–ธ.ค. 7 เดือน,
> 2569: ม.ค.–ก.ย. 9 เดือน) จึงไม่ควรเทียบยอดรวมข้ามปีโดยตรง ตัวหารคือประชากรตามทะเบียนราษฎร
> (ปี 2568 ณ 31 ธ.ค. 2567, ปี 2569 ณ มิ.ย. 2569) เขตชั้นในที่มีประชากรแฝงมากอาจมีอัตราสูงเกินจริง

## 8. ธีมสี (ไม่บังคับ)

**มุมมอง (View) → ธีม → เรียกดูธีม** แล้วเลือกไฟล์ [`powerbi/theme.json`](../powerbi/theme.json)
ถ้าเว็บไม่มีเมนูนี้ ให้เลือกธีมสำเร็จรูปที่ใกล้เคียงแทน

## 9. แชร์รายงาน

- **แชร์ให้อาจารย์หรือเพื่อนในมหาวิทยาลัย**: เปิดรายงาน → **แชร์** → ใส่อีเมลมหาวิทยาลัย (ผู้รับต้อง login จึงจะดูได้)
- **ฝังในเว็บแบบสาธารณะ (Publish to web)**: ไฟล์ → ฝังรายงาน → เผยแพร่ไปยังเว็บ
  ⚠️ วิธีนี้**ทุกคนบนอินเทอร์เน็ตเปิดดูได้** และหลายมหาวิทยาลัยปิดเมนูนี้ไว้ ใช้เฉพาะเมื่ออาจารย์อนุญาต

## 10. อัปเดตข้อมูลเมื่อรัน pipeline ใหม่

1. รัน DAG ใหม่ แล้วสั่ง `python -m spark.export_powerbi` (ดูขั้นที่ 0)
2. ถ้านำเข้าจาก OneDrive: เขียนทับไฟล์ใน OneDrive → ใน workspace คลิก semantic model → **รีเฟรชทันที**
3. ถ้านำเข้าจากเครื่อง: ต้องนำเข้าไฟล์ใหม่อีกครั้ง
